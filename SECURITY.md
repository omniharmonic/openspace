# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Email security@openspace.host with a description, reproduction steps and the affected version. We aim to acknowledge reports within 3 business days and to ship a fix or mitigation within 90 days.

## Scope

In scope: Studio, Hub, the `@omniharmonic/openspace-*` packages, templates, and the Claude Code plugin. Of particular interest: authentication and member gating, webhook signature verification, sandboxing of code and embed blocks, secret leakage into site content, and price tampering in checkout.

## Supported versions

Until 1.0, only the latest release on `main` receives security fixes.
